# Ad Budget Optimizer (DP vs Greedy)

## Features
- Dynamic Programming vs Greedy comparison
- INR currency support
- Editable ads
- Graph visualization

## Tech Stack
- C (Algorithm)
- Node.js (Backend)
- React (Frontend)

## Run Instructions

### Backend
cd backend
gcc knapsack.c -o knapsack
npm install
node server.js

### Frontend
cd frontend
npm install
npm start
